# Drawing Workbench

## Purpose

This project uses a reusable drawing workflow for logos, icons, UI prototypes, transparent assets, and future Figma MCP design handoffs.

## Tool Priority

1. WPF/SVG vector for desktop UI graphics and app icons.
2. imagegen for generated bitmap concepts and transparent cutouts.
3. Photoshop for local manual refinement.
4. Figma MCP for formal UI prototypes and component systems after explicit approval.

## Asset Locations

- `assets/design/`: prototype images, concept previews, screenshots.
- `assets/icons/`: SVG marks, WPF vector snippets, app icons.
- `docs/design/`: design decisions and handoff notes.

## First Validation Asset

The first reusable asset is the eye entry mark:

- SVG preview: `assets/icons/eye-entry-prototype.svg`
- WPF vector snippet: `assets/icons/eye-entry-icon.xaml`

The mark is intended for the compact desktop floating entry state before the transparent chat panel opens.
