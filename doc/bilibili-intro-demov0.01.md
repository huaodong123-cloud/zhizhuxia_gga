# 智助侠 demov0.01 概念版

智助侠是一个面向游戏场景的 Windows 原生 AI 攻略小工具。

它的目标不是做一个普通聊天窗口，而是做一个可以在游戏过程中低遮挡唤出的透明插件：平时隐藏在屏幕边缘，需要时通过快捷键打开，支持文字提问、区域截图、视觉分析、联网搜索和攻略回答。

当前版本为 `demov0.01 概念版`，重点验证产品方向和基础工作流。

## 项目定位

玩游戏时，很多问题并不是一句话能说清楚的。

例如：

- 当前任务提示是什么意思？
- 地图上这个标记应该怎么走？
- 背包里的装备该怎么选？
- Boss 机制现在触发了什么？
- 角色状态异常来自哪里？
- 截图里的 UI、数值、图标代表什么？

智助侠希望解决的是这一类问题：让 AI 能结合玩家当前画面和联网资料，给出更贴近上下文的攻略建议。

它不是外挂，不读取游戏内存，不修改游戏文件，也不注入游戏进程。当前版本只基于用户主动输入的问题和主动框选的截图进行分析。

## 核心能力

### 1. 游戏内低遮挡入口

智助侠使用 Windows 原生 WPF 实现，不使用 Electron、Tauri 或 WebView2。

主窗口设计为透明 HUD 风格，默认贴近屏幕边缘显示，尽量减少对游戏画面的遮挡。收起状态下只保留一个蜘蛛眼轮廓图标，颜色和透明度可以配置。

默认快捷键：

- 显示 / 隐藏：`Ctrl + Alt + F9`
- 区域截图：`Ctrl + Alt + F10`

快捷键避开了常见游戏操作键位，例如 WASD、Q、E、R、F、G、数字键、空格和 Tab。

### 2. 托盘配置

配置入口不放在游戏内主窗口里，而是放在 Windows 右下角托盘图标中。

用户可以通过托盘右键菜单进入配置窗口：

- 显示 / 隐藏智助侠
- 区域截图
- 配置
- 退出

配置窗口支持：

- 智谱 API Key
- 图标颜色
- 图标透明度
- 面板透明度
- 聊天气泡透明度
- 窗口置顶
- 收起态鼠标穿透开关占位

API Key 会缓存在当前 Windows 用户目录，方便下次启动继续使用。

缓存位置：

```text
%LOCALAPPDATA%\Zhizhuxia\visual-settings.json
```

### 3. 区域截图

用户点击截图按钮或按下截图快捷键后，主窗口会临时隐藏，并进入半透明全屏框选层。

用户拖拽选择游戏画面区域后，截图会以内存中的 PNG base64 形式传给本地后端，不需要用户手动保存图片。

截图流程：

1. 隐藏主窗口。
2. 显示全屏区域选择层。
3. 鼠标拖拽框选区域。
4. 截取 PNG。
5. 转为 base64。
6. 回到聊天窗口并显示截图已添加状态。

按 `Esc` 可以取消截图。

### 4. AI 工作流

智助侠不是简单把用户问题直接丢给模型，而是按场景走不同流程。

普通文字问题：

```text
用户问题 -> 意图识别 -> 联网搜索 -> GLM-5.2 生成回答
```

带截图的问题：

```text
用户问题 + 截图
-> 意图识别
-> GLM-5.2 视觉分析截图
-> 根据视觉结论生成搜索关键词
-> 搜索 B 站 / 小黑盒资料
-> GLM-5.2 结合问题、截图分析、搜索来源生成回答
```

当前搜索顺序：

1. B 站
2. 小黑盒

如果搜索失败，系统不会伪造来源，会在响应中返回明确的失败信息。

## 技术结构

项目由两个主要部分组成。

### 桌面端

路径：

```text
desktop/
```

技术：

- C#
- WPF
- Windows Forms NotifyIcon
- Windows API 全局快捷键
- HttpClient

桌面端职责：

- 原生窗口
- 托盘菜单
- 全局快捷键
- 区域截图
- 设置窗口
- 本地配置缓存
- 调用本地 Node API

### 本地后端

路径：

```text
server/
```

技术：

- Node.js
- REST JSON API
- 智谱 GLM-5.2 调用
- 搜索适配器
- 工作流编排

后端职责：

- `/api/chat`
- `/api/health`
- 意图识别
- 视觉分析
- 联网搜索
- Agent 选择
- 回复生成
- harness warning

桌面端会检查本地服务是否可用。如果不可用，会尝试启动：

```text
node server/src/server.js
```

默认服务地址：

```text
http://localhost:5177
```

## 运行方式

概念版包：

```text
dist/zhizhuxia-demov0.01-concept-win.zip
```

普通用户运行方式：

1. 下载并解压 `zhizhuxia-demov0.01-concept-win.zip`。
2. 打开解压后的文件夹。
3. 双击 `智助侠.exe`。
4. 在 Windows 右下角托盘隐藏图标中找到智助侠图标。
5. 右键图标，进入配置。
6. 填写智谱 API Key 并保存。
7. 使用 `Ctrl + Alt + F9` 显示 / 隐藏主窗口。
8. 使用 `Ctrl + Alt + F10` 进行区域截图。

启动后，桌面端会自动检查本地服务。如果服务没有运行，会尝试启动随包携带的 Node 后端：

```text
node server/src/server.js
```

当前概念版仍依赖本机安装：

- .NET Windows Desktop Runtime / SDK
- Node.js

后续版本会继续改进安装和分发方式。
